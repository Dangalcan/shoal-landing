Core features

Everything you need to operate Kubernetes, locally.

A single, fast, native desktop app — no browser tabs, no half-finished web dashboards. Built with Electron, React 19, and TypeScript.

One-click clusters

Spin up local clusters with kind, minikube, or k3d. Switch between contexts in a dropdown. Delete them just as easily.

Live resource explorer

Browse Pods, Services, Deployments, Ingresses, and every other Kubernetes resource with live status and YAML inspection.

Logs & shells

Tail container logs in real time, attach a shell to any pod, and pipe output back to your terminal of choice.

Secure by default

Sandboxed renderer, signed plugins, local-first storage. Your cluster credentials never leave your machine.

Extensible plugin API

Register sidebar items, add pages, attach resource actions, and ship notifications — all from a few dozen lines of JS.

Built for speed

Vite-powered hot reload, IPC-native architecture, and a tight 64 MB install. Opens in under a second on modern hardware.

Cluster lifecycle

From zero to running cluster in three commands.

Whether you're testing an operator or running a full dev environment, the cluster tooling is first-class. Create, pause, snapshot, and delete — all from the app, with no memorized flags.

  • Driver auto-detect for Docker, Podman, and containerd
  • Multi-cluster context switcher with live health checks
  • Works offline — no telemetry, no login, no cloud account
  • Kubeconfig stays in ~/.kube/config

Architecture

Native desktop. Sandboxed plugins. Zero cloud.

Three layers, one app. Every process is isolated, every plugin is signed, and your cluster data never leaves your machine.

Main process

Electron main runs the app lifecycle and brokers every OS call — docker, kubectl, kind — through a typed IPC bridge.

Renderer UI

A sandboxed React 19 app powered by Vite, Tailwind v4, and React Router. No Node APIs, no fs, no escape.

Plugin runtime

Plugins are cryptographically signed bundles with declared permissions. License keys and trials are handled by the marketplace backend.

Quickstart

Get your first cluster in under a minute.

Three steps. No sign-up. No credit card.

STEP 01

Install

Grab the installer for your platform, or use a package manager.

$ brew install --cask kubernetes-desktop
STEP 02

Create a cluster

Pick kind, minikube, or k3d. We'll install the driver if needed.

$ kd create cluster --driver kind
STEP 03

Explore

Browse resources, install plugins, and start shipping.

$ kd open

Your cluster, on your desktop.

Open source, local-first, and free forever for the core app. Download it once — then customize it with whichever plugins fit your workflow.
